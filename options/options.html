LiChessable

The Lichess opening explorer requires authentication. Create a free personal access token — leave all scope checkboxes unchecked, the explorer only needs a valid token, no permissions — and paste it below.

Auto runs the lite Stockfish build on low-power devices (phones, ≤4 cores or ≤4 GB memory) and the full build elsewhere; Full/Lite forces one. Each build must be downloaded to engine/vendor/ first — see the README's "Local engine" section.

Review auto-play (the toggle on the in-session Overstudy widget): auto-played moves count as normal correct answers — the move was proven earlier this session, and Chessable schedules it as passed. Failed or timed-out moves are never auto-played, and a move is never auto-played the first time it appears in a session. Nothing is remembered across browser sessions.

The token is stored only in this browser's extension storage (chrome.storage.local) and is sent only to explorer.lichess.org. You can revoke it any time on your Lichess token page.

Loaded version: ? — the build Chrome currently has in memory. It only changes when the extension itself is reloaded, so it is the quickest way to check whether an edit has actually taken effect.
